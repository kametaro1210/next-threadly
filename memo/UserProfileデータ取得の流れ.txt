
==========================================
ログインユーザーのプロフィール取得の流れ
==========================================

UserProfileの定義からログインユーザーの情報を取得し、
Neonのuser_profilesテーブルに保存するまでの流れを説明します。

------------------------------------------
1. テーブルを準備する
------------------------------------------

- prisma\schema.prisma
UserProfileモデルで、user_profilesテーブルと列を定義します。

npm run db:push
schema.prismaの定義をNeonのデータベースに反映し、テーブルを作成します。
続けてPrisma Clientも生成します。
このコマンドはテーブル構造を作るもので、ユーザーのデータは登録しません。

------------------------------------------
2. ログインユーザーを確認する
------------------------------------------

- app\(core)\layout.tsx
共通レイアウトの表示時にgetSessionUserを呼び出します。
ログインしていない場合はnullが返り、プロフィールの検索・登録は行いません。

- lib\auth.ts
getSessionUserがNeon Authから現在のセッションを取得します。
ログイン中なら、そのユーザー情報をensureUserProfileに渡します。

------------------------------------------
3. プロフィールを取得・登録する
------------------------------------------

- lib\db\user-profile.ts
ensureUserProfileがNeon AuthのユーザーIDでuser_profilesを検索します。

すでに登録されていれば、そのプロフィールを使います。
見つからなければ、usernameを生成し、ユーザーIDとともに新しい行を登録します。
created_atはテーブル定義の初期値により設定されます。

- lib\types.ts
User型で、アプリ内で使うユーザー情報（id、username、displayName、avatarUrl）を定義します。
DBのテーブル定義ではなく、ensureUserProfileの戻り値の形を表します。

- lib\prisma.ts
Prisma Clientを作成し、DATABASE_URLを使ってNeonのデータベースに接続します。

------------------------------------------
4. 取得した情報について
------------------------------------------

ensureUserProfileが返したUserは、app\(core)\layout.tsxのuser変数に入ります。

つまり、npm run db:pushでテーブルを作成し、
ログイン中に(core)配下へアクセスするとプロフィール行が取得・登録されます。
これはNeon上のテーブルへの保存であり、画面上への一覧表示とは別です。
